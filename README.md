## Deployment

### Podman Compose

```yaml
services:
  syncthing:
    image: "ghcr.io/daemonless/syncthing:latest"
    container_name: syncthing
    volumes:
      - "/containers/syncthing:/config"
    ports:
      - "8384:8384"
      - "22000:22000"
      - "22000:22000"
      - "21027:21027"
    # always (not unless-stopped) so FreeBSD's podman rc.d auto-starts it at boot
    restart: always
```

Save as `compose.yaml`, then run `podman-compose up -d`.

### AppJail Director
**.env**:

```
# .env

DIRECTOR_PROJECT=syncthing
```

**appjail-director.yml**:

```yaml
# appjail-director.yml

options:
  - virtualnet: ':<random> default'
  - nat:
services:
  syncthing:
    name: syncthing
    options:
      - container: 'args:--pull'
      - expose: '8384:8384 proto:tcp'
      - expose: '22000:22000 proto:tcp'
      - expose: '22000:22000 proto:udp'
      - expose: '21027:21027 proto:udp'
    volumes:
      - syncthing: /config
volumes:
  syncthing:
    device: '/containers/syncthing'
```

**Makejail**:

```
# Makejail

ARG tag=latest

OPTION container=boot
OPTION overwrite=force
OPTION from=ghcr.io/daemonless/syncthing:${tag}
```

Save the files above, then run `appjail-director up`.


> [!WARNING]
> Exposing ports in AppJail means that your service can be reached from remote hosts. If that is not your intention, do not expose the ports and communicate with the service using the jail's IPv4 address or hostname assigned by the virtual network.
>
> To avoid exposing ports, just remove the `expose` option in your `appjail-director.yml` or from your command-line arguments.

### Bastille

> [!WARNING]
> Bastille's OCI support is **experimental**. It requires `buildah` and shares the host network stack (`inherit`). Mount volumes with `--volume HOST JAIL`; without it, image-declared volumes are stored under `${bastille_volumesdir}/${jail}`.

```yaml
services:
  syncthing:
    name: syncthing
    image: "ghcr.io/daemonless/syncthing:latest"
    network:
      - mode: host
```

Save as `bastille-compose.yml`, then run `bastille up`.
